What You Will Learn

8-week structured course plan

Week 1

Linux Basics

Navigate file systems, use command line tools, and understand core Linux workflows.

Week 2

Linux + HPC + Bash Scripting

Work on servers, automate tasks, and build reproducible command-line pipelines.

Week 3

Python for Biology

Handle biological data, visualize results, and explore Python tools for research.

Week 4

R for Bioinformatics

Perform analysis with R, ggplot2, and dplyr for data-driven research.

Week 5

RNA-seq Analysis

Process raw RNA-seq data to discover gene expression patterns and insights.

Week 6

Functional Analysis

Learn GO, KEGG, and pathway enrichment to interpret biological meaning.

Week 7

Research Workflow

Build GitHub portfolios, practice reproducible research, and review scientific papers.

Week 8

Final Project

Apply skills to a real dataset and prepare a report with research-ready results.
